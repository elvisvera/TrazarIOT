# 🌱 AgroMonitor Pro v3.0

## Sistema Profesional de Monitoreo Agrícola para Café y Cacao

### 🎯 Características Principales

#### 📊 Dashboard General
- KPIs en tiempo real (GDD, Calidad, Balance Hídrico, Alertas)
- Resumen por tipo de cultivo (Café / Cacao)
- Gráficas evolutivas interactivas

#### 🌿 Módulo Fenológico
- Seguimiento de etapas de desarrollo
- Progreso a madurez
- Balance hídrico por estación

#### 🏆 Módulo de Calidad
- Índice de Calidad Predictiva (PQ)
- Perfil de taza predictivo (Acidez, Cuerpo, Aroma, Dulzor)
- Clasificación de calidad

#### 🚨 Sistema de Alertas
- Alertas por condiciones climáticas extremas
- Detección de riesgo de Roya (café)
- Alertas fenológicas (floración, maduración)
- Recomendaciones de acción

#### 📱 Trazabilidad (Nuevo Módulo Unificado)
- **Gráficas completas del cultivo**:
  - Evolución de indicadores (Temperatura, Humedad, GDD)
  - Temperatura: Promedio, Máxima y Mínima
  - Humedad: Promedio, Máxima y Mínima
  - Temperatura Nocturna vs Promedio Diario
  - Déficit de Presión de Vapor (VPD)
  - Horas con Humedad > 90%
  - Precipitación y Radiación Solar
- **Líneas verticales fenológicas**:
  - Botón Floral 🌱
  - Floración 🌸
  - Llenado de Fruto 🌿
  - Maduración 🍒
  - Cosecha ☕
- **Configuración manual de fechas** para cada etapa
- **Tabla detallada** con todos los indicadores y etapa asignada
